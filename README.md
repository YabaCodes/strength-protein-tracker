# Strength + Protein Tracker

Static PWA. No backend required.

## Run locally
Use any local static web server. Example:
python3 -m http.server 8000

Then open http://localhost:8000/workout-protein-tracker/ if serving /mnt/data,
or run the server from this folder and open http://localhost:8000/.

## GitHub Pages
1. Create a new repository.
2. Upload the contents of this folder to the repository root.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. Open the Pages URL in Safari.
5. iPhone/iPad: Share → Add to Home Screen.

All app data is stored in browser localStorage. Use Settings → Export JSON for backups.
